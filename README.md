# Bhojraj Joshi - Portfolio

A professional dark space-themed portfolio website showcasing my work as an AI Engineer and Full Stack Developer.

## 🌟 Features

- **Dark Space Theme** - Professional design with animated stars and space background
- **Fully Responsive** - Optimized for desktop, tablet, and mobile devices
- **Dynamic Content** - All data loaded from JSON files for easy updates
- **Smooth Animations** - Premium transitions and hover effects
- **Modern UI/UX** - Clean, minimal design following industry best practices

## 🛠️ Technologies Used

- HTML5
- CSS3 (Custom Properties, Flexbox, Grid)
- Vanilla JavaScript
- Google Fonts (Inter, Fira Code)

## 🚀 Getting Started

1. Clone the repository:
```bash
git clone https://github.com/Joshiaryan/portfolio.git
```

2. Open `index.html` in your browser or use a local server:
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve
```

3. Visit `http://localhost:8000` in your browser

## 📝 Updating Content

All content is stored in JSON files in the root directory:

- `personal.json` - Personal information and contact details
- `about.json` - About section content
- `education.json` - Educational background
- `skills.json` - Technical skills and languages
- `projects.json` - Project details
- `activity.json` - Latest activities

Simply edit these files and refresh the page to see changes.
